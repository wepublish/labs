Aldus — Slack setup

Aldus is our We.Publish support/knowledge agent, already running on hermes01.wepublish.cloud. It connects to Slack via Socket Mode (outbound only — no public URL or firewall changes needed). The steps below need a workspace admin, ~10 minutes.

  1. Create the app from the manifest

    api.slack.com/apps → Create New App → From a manifest

    Pick the We.Publish workspace, choose JSON, paste the manifest below, create. It pre-configures all scopes, events, Socket Mode, and commands.

  2. Generate the app-level token

    Basic Information → App-Level Tokens → Generate Token and Scopes

    Name it aldus-socket, add the connections:write scope, generate. Copy the token (xapp-…).

  3. Install the app to the workspace

    Install App → Install to Workspace

    Allow, then copy the Bot User OAuth Token (xoxb-…).

  4. Create the channels, invite Aldus

    Slack

    Create #dev-aldus and #support-aldus as private channels; in each, type /invite @Aldus.

  5. Collect the channel IDs

    Channel name → View channel details → About (bottom)

    Copy the Channel ID of each (looks like C0123ABCDEF). We pin Aldus to exactly these two — it won't respond anywhere else.

Alternative: fixing an existing app by hand

If an app already exists and you prefer not to paste the manifest, add these bot token scopes (OAuth & Permissions): groups:read, groups:history, channels:read, mpim:read, im:read, users:read — plus chat:write and app_mentions:read if not present. Then under Event Subscriptions (toggle on; no Request URL needed with Socket Mode) subscribe to bot events message.groups, message.channels, app_mention. Finally reinstall the app — scope changes don’t apply until reinstall. If the xoxb- token changes, send us the new one. (The manifest additionally adds slash commands and renames the bot to Aldus — both optional.)
